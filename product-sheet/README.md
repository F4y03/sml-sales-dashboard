# ตารางสินค้าแยกจาก Dashboard

รันจากโฟลเดอร์หลักด้วย `node product-sheet/server.js` แล้วเปิด http://localhost:3002

- ใช้สำเนา CSV ใน `data/products.csv` ไม่เปลี่ยนไฟล์ต้นฉบับ
- ตารางแสดงหน้าละ 100 รายการ คลิกเซลล์เพื่ออ่านค่าเต็ม
- ดาวน์โหลด Excel ครบทุกแถว 48 คอลัมน์ เรียงตามต้นฉบับ
- เซลล์เป็นข้อความเพื่อรักษารหัสและเลขศูนย์นำหน้า HTML ในคำอธิบายเก็บเป็นข้อความ
- ปรับรูปแบบตัวขึ้นบรรทัดใหม่เป็น LF ให้ข้อมูลบนเว็บตรงกับ Excel
- ไม่เชื่อมฐานข้อมูลหรือระบบ Dashboard; เปิดเฉพาะเครื่องนี้ที่พอร์ต 3002
