Data Protection.

How this dashboard handles marketplace data (Shopee, Lazada, TikTok Shop) · การคุ้มครองข้อมูลของระบบนี้

1. What we store · ข้อมูลที่เก็บ

2. Retention and deletion · ระยะเวลาเก็บและการลบ

  • Shopee data received through the API: the buyer province is cleared once the order is older than 90 days; Shopee API call logs are deleted after 90 days.
  • Every import (file upload or API sync) is listed in the upload history and can be deleted by an administrator; deleting it removes its orders, items and fee rows.
  • Disconnecting a shop deletes its access tokens; already imported orders stay until deleted as above.
  • Local backups of the dashboard database are kept for 30 days on the company server only.

3. Access control · การควบคุมการเข้าถึง

  • Sign-in with password and two-factor authentication (TOTP) for staff accounts.
  • Role-based permissions: each account sees only the pages its role allows; online-sales figures need a dedicated permission.
  • Connecting a shop and changing system settings are limited to the Super Admin.
  • This review account is read-only: it can view online sales, its own activity log and this page; uploads, deletion, exports and settings are blocked on the server (HTTP 403).

4. Security · ความปลอดภัย

  • All traffic uses HTTPS.
  • Marketplace access tokens and 2FA secrets are encrypted at rest (AES-256-GCM); app secrets are kept in server configuration only, never in the browser or source code.
  • Every sign-in and data action is recorded in the activity log (who, what, when, from which IP).
