สร้าง Dashboard ใน Excel ทีละขั้น

สำหรับ Excel บน Windows ที่มี PivotTable และ Slicer · ยอดในหน้านี้หมายถึงจำนวนสินค้า ไม่ใช่ยอดเงิน

1. เตรียมตารางข้อมูล

สร้างชีต Data ใส่คอลัมน์ วันที่ทำรายการ, รหัสลูกค้า, ภูมิภาค, ชื่อสินค้า, ประเภทรายการ, จำนวน, ยอดคงเหลือ แล้วเลือกข้อมูล กด Ctrl+T ติ๊ก My table has headers ตั้งชื่อตารางว่า Movements

วันที่ต้องเป็นวันที่จริง จำนวนเป็นตัวเลขไม่ติดลบ ประเภทรายการใช้ รับเข้า หรือ เบิกออก เท่านั้น ใช้หน่วยเดียวกันก่อนรวมยอด และใช้รหัสสินค้าแทนชื่อหากชื่อซ้ำกัน คงเหลือหมายถึงยอดหลังแต่ละรายการ ต้องมีข้อมูลล่าสุดครบทุกคู่ลูกค้า–สินค้า รวมคู่ที่ไม่มีความเคลื่อนไหวในช่วงนี้

สร้างตารางชื่อ RegionMap โดยมีคอลัมน์ รหัส และ ภูมิภาค:

รหัสภูมิภาค
ฝกจ, ฝกณ, ฝกต, ฝกร, ฝกภ, ฝบอ (แยกเป็น 6 แถว)ภาคกลาง
ฝหยภาคเหนือ
ฝตชภาคใต้
ฝลภภาคตะวันออก
ฝอยภาคอีสาน

ในคอลัมน์ภูมิภาคของ Movements ใส่สูตร (จับสามตัวแรก เช่น ฝหย-001):

=IFERROR(VLOOKUP(LEFT(TRIM([@[รหัสลูกค้า]]),3),RegionMap[[รหัส]:[ภูมิภาค]],2,FALSE),"ไม่ระบุภูมิภาค")

2. เพิ่มคอลัมน์สำหรับสรุปยอดที่ถูกต้อง

เพิ่ม เดือน โดยเก็บเป็นวันแรกของเดือน แล้วตั้งรูปแบบเซลล์ mmm yyyy เพื่อแยกปีด้วย:

=DATE(YEAR([@[วันที่ทำรายการ]]),MONTH([@[วันที่ทำรายการ]]),1)

เพิ่ม ยอดเบิก:

=IF([@[ประเภทรายการ]]="เบิกออก",[@จำนวน],0)

เรียงตามวันที่และเวลาหรือลำดับรายการจากเก่าไปใหม่ หากมีหลายรายการวันเดียวกัน ต้องทราบลำดับจริง เพิ่มคอลัมน์ ลำดับ เป็นเลข 1, 2, 3… ไม่ซ้ำกันและเก็บเป็นค่า หลังเพิ่มข้อมูลใหม่ให้ใช้เลขต่อเนื่อง

เพิ่ม คงเหลือล่าสุด เพื่อใช้เฉพาะแถวล่าสุดของลูกค้า–สินค้าแต่ละคู่ แถวอื่นให้เป็น 0:

=IF(COUNTIFS(Movements[รหัสลูกค้า],[@[รหัสลูกค้า]],Movements[ชื่อสินค้า],[@[ชื่อสินค้า]],Movements[ลำดับ],">"&[@ลำดับ])=0,[@ยอดคงเหลือ],0)

ตัวอย่าง รับเข้า 100 คงเหลือ 100 แล้วเบิก 20 คงเหลือ 80 → ยอดเบิก 20 และคงเหลือ 80 ไม่ใช่ 180 ห้ามใช้ Sum หรือ Max ของคงเหลือเดิมแทนสูตรนี้

3. สร้าง PivotTable ชุดแรก แล้วคัดลอก

คลิก Movements → Insert → PivotTable → New Worksheet ตั้งชื่อชีต Pivots และตั้งชื่อ Pivot แรก PT_KPI จากนั้นคัดลอก Pivot นี้อีก 3 ชุด วางให้ห่างกันเพื่อเผื่อขยาย ตั้งชื่อ PT_Region, PT_Month, PT_Customer วิธีนี้ช่วยให้ใช้แหล่งข้อมูลและ Pivot Cache ร่วมกัน

PivotRowsValues (Sum)
PT_KPIไม่ต้องใส่ยอดเบิก, คงเหลือล่าสุด
PT_Regionภูมิภาคยอดเบิก
PT_Monthเดือน (เรียงเก่าไปใหม่)ยอดเบิก
PT_Customerรหัสลูกค้าคงเหลือล่าสุด

ตรวจ Value Field Settings ให้เป็น Sum ไม่ใช่ Count ไม่ต้องกรองประเภทรายการเป็นเบิกออก เพราะคอลัมน์ยอดเบิกแยกไว้แล้ว และการกรองนั้นอาจตัดแถวคงเหลือล่าสุดที่เป็นรับเข้า

4. ดึง PivotChart และจัดหน้า Dashboard

  1. สร้างชีต Dashboard คลิก PT_Region → PivotTable Analyze → PivotChart → Bar / Clustered Bar แล้ว Move Chart → Object in: Dashboard
  2. คลิก PT_Month → PivotChart → Line แล้วนำไปวางที่ Dashboard หากต้องแสดงเดือนว่าง ให้เตรียมรายการเดือนครบและกำหนดให้แสดงรายการที่ไม่มีข้อมูลตามโครงสร้างต้นทาง
  3. คลิก PT_Customer → PivotChart → Doughnut เปิด Data Labels เป็นชื่อรหัสและเปอร์เซ็นต์ หากมีคงเหลือติดลบให้แก้ข้อมูลก่อนแสดงสัดส่วน หากรุ่น Excel ไม่รองรับ ให้สร้าง Doughnut ปกติจากช่วงสรุปที่ลิงก์กับ Pivot โดยไม่รวม Grand Total และตรวจว่าช่วงกราฟขยายครบเมื่อเพิ่มลูกค้า
  4. สร้าง KPI ในเซลล์ Dashboard โดยพิมพ์ = แล้วคลิกยอดรวมที่ PT_KPI เพื่อให้ Excel สร้าง GETPIVOTDATA ให้อัตโนมัติ เปิด Generate GetPivotData หากยังไม่สร้างสูตร จัดตัวเลขให้ใหญ่ หรือใช้ Text Box ที่ลิงก์กับเซลล์ KPI

5. เชื่อม Slicer ให้ควบคุมทุกกราฟ

  1. คลิก Pivot ใดก็ได้ → PivotTable Analyze → Insert Slicer → เลือก รหัสลูกค้า และ ภูมิภาค
  2. ย้าย Slicer ทั้งสองไปชีต Dashboard
  3. คลิกขวา Slicer รหัสลูกค้า → Report Connections / PivotTable Connections → ติ๊ก PT_KPI, PT_Region, PT_Month, PT_Customer ให้ครบ → OK
  4. ทำซ้ำกับ Slicer ภูมิภาค ทั้งสองตัวต้องเชื่อมครบทั้ง 4 Pivot
  5. คลิก ฝหย: KPI และกราฟทั้งหมดควรเหลือข้อมูลภาคเหนือ ใช้ Ctrl หรือปุ่ม Multi-Select เพื่อเลือกหลายรหัส และใช้ Clear Filter เพื่อล้าง เลือกสอง Slicer ร่วมกันจะเป็นเงื่อนไขตัดกัน

ถ้า Pivot ไม่ปรากฏใน Report Connections ให้ตรวจว่าใช้ตารางต้นทางและ Cache เดียวกัน วิธีแก้ที่ตรงไปตรงมาคือคัดลอก Pivot ที่เชื่อมได้ แล้วจัด Rows/Values ใหม่

6. ตรวจยอดและอัปเดต

ทดลองเลือกทีละภูมิภาค เทียบยอดกับรายการต้นทาง ตรวจคู่ที่แถวล่าสุดเป็นรับเข้า ตรวจเดือนข้ามปี และทดสอบตัวกรองที่ไม่มีข้อมูล เมื่อเพิ่มแถวใน Movements ให้ต่อเลขลำดับ ตรวจสูตรคงเหลือล่าสุด แล้ว Data → Refresh All

ยอดคงเหลือเป็นยอดล่าสุดตามไฟล์ ไม่ใช่ยอดสด ณ วันนี้โดยอัตโนมัติ อย่าเชื่อม Timeline วันที่เข้ากับ Pivot คงเหลือแบบนี้ เพราะจะตัดสินค้าที่ไม่เคลื่อนไหวในช่วงที่เลือก หากต้องการคงเหลือ ณ วันย้อนหลัง ต้องคำนวณแถวล่าสุดก่อนหรือเท่ากับวันนั้นใหม่
